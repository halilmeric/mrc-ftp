# MRC FTP sürüm 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (bu oturumda, satır içi).

**Goal:** SFTP bağlantısı (şifre ya da SSH anahtarı, sunucu anahtarı parmak izi) ve altta açılan, ayrılabilen terminal.

**Architecture:** FTP ve SFTP aynı oturum arayüzünü uygular; kuyruk, düzenleme ve önizleme yalnızca bu arayüzü çağırır. Terminal oturumu ana süreçte yaşar, çıktıyı arayüze olay olarak yollar; ayrılan pencere aynı oturumun ikinci görünümüdür.

**Tech Stack:** Electron 45, basic-ftp, ssh2 1.17.0, @xterm/xterm 6.0.0, @xterm/addon-fit 0.11.0, node:test.

**Spec:** `docs/superpowers/specs/2026-11-19-mrc-ftp-v3-design.md`

## Global Constraints

- Şifre, anahtar ve anahtar parolası sunucu parmak izi onaylanmadan gönderilmez.
- Anahtar dosyası kopyalanmaz; yalnızca yolu saklanır. Parola `safeStorage` ile saklanır.

- Commit mesajları tek satır.

## Oturum arayüzü (Task 1'in ürettiği, herkesin tükettiği)

```
list(path) -> [{name,size,isDir,modified,mode}]
mkdir(path) · rename(from,to) · chmod(path,mode) · remove(path,isDir)
fetch(remote, local)                     // yeniden bağlanarak dener, FtpError atar (düzenleme/önizleme)
download(remote, local, {offset,onProgress})   // tek deneme, ham hata (kuyruk)
upload(local, remote, {offset,onProgress})     // tek deneme, ham hata (kuyruk)
abort()                                  // süren aktarımı bağlantıyı keserek durdurur
close()
```
Ham hatada `typeof err.code === 'number'` = sunucu reddetti; `err.syscall && err.path` = Mac'teki dosya; diğerleri = bağlantı koptu. `onProgress(bytes)` bu denemede aktarılan baytı verir.

## Review Focus

1. SFTP'de var olan dosyanın üzerine yükleme: taşıma atomik mi, eski dosya kaybolabilir mi.
2. Yarım SFTP aktarımını sürdürme: geçici dosyada boşluk kalmamalı (sıralı yazım).
3. Parmak izi eşleşmeden kimlik bilgisi gitmemesi (test sunucusunda giriş denemesi sayısı 0).
4. Sunucudaki sembolik bağlar (cPanel'de `www -> public_html`) klasör olarak listelenmeli.
5. Terminal: bağlantı kesilince/pencere kapanınca oturumun ve ayrılan pencerenin kapanması.

- **Produces:** `openSftpSession(cfg)` (arayüzün aynısı), `connectSsh(cfg) -> ssh2.Client`, `fingerprintOf(keyBuffer) -> 'SHA256:…'`. `cfg = {host,port,user,password,keyPath,passphrase,fingerprint}`.
- Hatalar: parmak izi yok → `CERT` `{cert:{reason:'ssh-new',fingerprint}}`; farklı → `reason:'ssh-changed'`; giriş reddi → `AUTH`; parolalı anahtar, parola yok → `NEED_PASSWORD`; yanlış parola → `AUTH`; anahtar okunamıyor → `LOCAL`; SFTP durum hatası → `FTP`.
- [ ] Test sunucusu: `startSshServer({files, slow, shell})` → `{port, root, user, password, fingerprint, clientKey, lockedKey, passphrase, auths, drop(), stop(), rekey()}`.
- [ ] Testler (kırmızı): listeleme (dosya, klasör, sembolik bağ, izin, tarih); mkdir/rename/chmod/remove (dolu klasör); ilk bağlantı `ssh-new` ve `auths === 0`; güvenilen parmak iziyle bağlanma; `ssh-changed`; yanlış şifre `AUTH`; anahtarla giriş; parolalı anahtar (parolasız `NEED_PASSWORD`, parolayla tamam); kuyrukla yükleme/indirme; var olanın üzerine yükleme; kopma sonrası sürdürme (iki yön); iptalde geçici dosya kalmaması.
